# Decks, tags, and folders

By default, notes tagged `#flashcards` provide cards. A tag can appear anywhere in a note. Use **Settings → Sources → Flashcard tags** to set one or more tags. Tags separated by spaces are accepted, and subtags belong to their parent tag.

## Folders as decks

Turn on **Use folders as decks** to make each folder a deck instead of using its card tag. Nested folders become nested decks. This is useful when your vault already follows a subject hierarchy.

## Exclusions

**Tags to skip** keeps tagged notes out of flashcard scanning. **Skipped folders** excludes folders or patterns such as `**/*.excalidraw.md` from both cards and note review. The default skipped pattern is `**/*.excalidraw.md`.

Deck selection is available when starting review, custom study, statistics, FSRS optimisation, and exams.
