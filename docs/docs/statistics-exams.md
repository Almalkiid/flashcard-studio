# Statistics and exams

## Statistics

Open **Statistics** to view activity, review count and time, retention, future due cards, card states, intervals, stability, difficulty, retrievability, answer buttons, and weak areas. Choose a deck and time range to narrow the view. Statistics fill in from your review log and can be refreshed.

Weak areas rank decks by recent retention against your target. A deck appears after ten review answers in the last 30 days.

## Exams

Run **Take an exam** from the command palette, dashboard, or desktop sidebar. Choose decks, question count, an optional time limit, and either multiple-choice only or all eligible cards. Cloze and suspended cards are excluded. An exam never changes a flashcard schedule.

To test yourself on particular notes, switch **Cards from** to **Notes** and use **Add note**, which searches the notes that have cards to ask. **Take an exam from this note**, in the command palette or a note's file menu, opens the setup with that note chosen. Retake, the setup that starts from your last exam, and a resumed exam keep the notes. A note renamed, deleted or left with nothing to ask is named and left out; with none left, the setup stays on **Notes** until you add one.

The included presets are **Quick check** (20 questions, no limit) and **CIA simulation** (125 questions, 150 minutes). You can flag questions, use the question map, and resume an unfinished exam on the device that started it, even when no cards are left to make a new exam from. Results show the score, pass-mark comparison, deck scores (note scores for an exam from several notes), answers, and **Study the ones I missed**. The default pass mark is 75%.

With AI set up for card generation and **All cards** chosen, the setup offers **AI checks typed answers**. On submit, each typed answer that does not match exactly gets the same check as **Check meaning with AI**: only the question, the expected answer and the typed answer are sent. An answer with the same meaning counts as right; a different meaning, an undecided check, a failure or a check over 10 seconds leaves it wrong. **Show results now** stops waiting; an answer then says whether it was not sent, or sent with no verdict back yet. The results and the exam file show the AI's verdict and reason for each checked answer. If the AI provider is changed after the exam starts, nothing is sent and every typed answer keeps its exact mark. Nothing is sent with the option off.
