### Card Syntax

These settings are on the flashcards page, under `Card syntax`.

| Setting                                                            | Default                     | What it does                                                                                                                                    |
| ------------------------------------------------------------------ | --------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| `Callout card types`                                               | `flashcard, question, card` | A callout of one of these types is a [callout card](flashcards/callout-cards.md). Empty turns callout cards off.                                |
| `Characters denoting the start of clozes and multiline flashcards` | empty                       | With the end marker, lets a card have [blank lines, tables and several paragraphs](flashcards/cards-with-blank-lines.md), also in its question. |
| `Cloze card is only the line with the cloze`                       | off                         | A [cloze card](flashcards/cloze-cards.md#atomic-clozes-only-the-line-with-the-cloze) is the line with the cloze, not the paragraph.             |
| `Clozes in LaTeX math`                                             | off                         | `\cloze{answer}{hint}` is a [cloze in math](flashcards/cloze-cards.md#clozes-in-math-latex).                                                    |
